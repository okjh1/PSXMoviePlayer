PSX Movie Player C#
===================
todo: document how to use

It is finished you just need to build and compile through cmake then you can pass the str file as the first argument. it works for normal v2 str files and only those.

This can be used as reference for those trying to implement the str file format as it is probably simpler to look at than jPSXdec.

Str file format documentation: https://github.com/m35/jpsxdec/blob/readme/jpsxdec/PlayStation1_STR_format.txt
